# آموزش جامع تک‌پورت کردن با HAProxy
این آموزش به شما کمک می‌کند پنل خود را مدیریت کنید.

> **توجه:** حتماً قبل از شروع، تیک پروکسی کلودفلر را خاموش کنید.

## قدم اول: نصب پیش‌نیازها
برای نصب ابتدا دستور زیر را وارد کنید:

\`\`\`bash
apt update && apt install -y haproxy certbot
\`\`\`

## قدم دوم: دریافت گواهینامه
حالا نوبت گرفتن سرتیفیکیت است:

\`\`\`bash
certbot certonly --standalone -d sub.example.com
\`\`\`
