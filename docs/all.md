کاراکترهای کلیدی مارک‌داون

# (هش): برای ساخت تیترها — تعداد هش‌ها سطح تیتر را مشخص می‌کند
* (ستاره): برای ایتالیک (یک ستاره)، بولد (دو ستاره) و لیست‌های نامرتب
_ (آندرلاین): جایگزین ستاره برای ایتالیک و بولد
> (علامت بزرگ‌تر): برای ساخت نقل‌قول
- و +: برای لیست‌های نامرتب و خط افقی
` (بک‌تیک): برای کد درون‌خطی — سه بک‌تیک برای بلوک کد
| (پایپ): برای ساخت جدول
[ ] (براکت): برای لینک و لیست وظایف
! (علامت تعجب): قبل از براکت برای تصویر
~~ (دو تیلد): برای خط‌خورده کردن متن
= و ---: برای تیترهای سطح ۱ و ۲ به سبک Setext
